item+ Support

Questions about the iOS app, the public website, self-hosted usage, or an App Review setup for item+ can be handled through the channels below.

E-mail

For general support, App Store review follow-up, and questions about the app or website.

hello@itemplus.app

Technical project issues

For reproducible bugs, feature requests, and technical discussion around the open-source project.

github.com/dncloud/itemplus/issues

Demo and review environments

item+ is a self-hosted system. The public website and the iOS app are not the same thing as a permanently hosted production server for all users. If review or support needs a prepared test system, a dedicated demo environment can be provided for that purpose.
